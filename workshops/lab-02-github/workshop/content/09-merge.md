title: "Step 7: merge"
---

Once your pull request is approved, merge it: *Merge pull request*, then *Confirm merge*. Keep that default,
a merge commit: step 8 relies on it.

Then open *Issues*: `#1` is closed, and points to the pull request that closed it.

GitHub offers to *Delete branch*: you can, its change is in `main` now.
