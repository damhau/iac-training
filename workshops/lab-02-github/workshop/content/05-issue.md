A change starts with a ticket. On GitHub, in `netops-lab`: *Issues*, *New issue*.

- **Title:** `Add read-only SNMP community to core-sw01`
- **Description:** why, for example `The monitoring server needs read-only SNMP access to core-sw01.`

*Create*. Note its number, after the title: `#1` in a new repository.
